# Website templates

Six free, responsive website templates. Plain HTML, CSS and JavaScript: no install, no build step.
Each one is a GitHub template repo: click **Use this template** to get your own copy.

**Gallery:** https://abdelmoulabilel.github.io/website-templates/

| Repo | Demo |
|---|---|

| [quilt-shop-template](https://github.com/AbdelmoulaBilel/quilt-shop-template) | [live demo](https://abdelmoulabilel.github.io/quilt-shop-template/) |
| [beauty-spa-template](https://github.com/AbdelmoulaBilel/beauty-spa-template) | [live demo](https://abdelmoulabilel.github.io/beauty-spa-template/) |

| [research-lab-template](https://github.com/AbdelmoulaBilel/research-lab-template) | [live demo](https://abdelmoulabilel.github.io/research-lab-template/) |
| [creative-agency-template](https://github.com/AbdelmoulaBilel/creative-agency-template) | [live demo](https://abdelmoulabilel.github.io/creative-agency-template/) |

Highlights: the mosque template calculates prayer times for any city in the browser, shows the Qibla, prints a monthly timetable and has a TV screen mode for the prayer hall (English, French, Arabic).
